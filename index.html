Menyusun halaman web dengan Bootstrap

Pelajari layout, komponen, dan form melalui contoh yang bisa langsung dicoba.

Konten

Feature 1

Grid Bootstrap membagi halaman menjadi 12 kolom, sehingga layout tetap rapi di desktop dan tersusun ke bawah di ponsel.

Feature 2

Navbar, card, tombol, dan modal tersedia sebagai komponen siap pakai. Cukup panggil class-nya pada elemen HTML.

Main Article

Bootstrap membantu pengembang membuat tampilan web yang konsisten dengan cepat. Gaya cukup ditambahkan melalui class pada elemen HTML, tanpa menulis CSS dari awal.

Selain CSS, Bootstrap menyediakan komponen JavaScript seperti modal, tab, collapse, dan toast. Semuanya aktif melalui atribut data-bs-*.

Komponen

Bilah navigasi di bagian atas halaman, tempat menu utama dan tombol akun.
